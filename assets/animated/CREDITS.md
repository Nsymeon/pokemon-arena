# Animated Pokémon artwork credits

Source: [PMD SpriteCollab](https://github.com/PMDCollab/SpriteCollab), revision `2b1c5ac0ca87b14ee023697dff322640eebcb50a`.

Original Mystery Dungeon sprites: Chunsoft / respective Pokémon rights holders. Community contributions follow the repository's [CC BY-NC 4.0 policy](https://github.com/PMDCollab/SpriteCollab#submission-and-use-policy). This is a noncommercial fan prototype.

The sprite sheets are unmodified. Runtime code selects frames, scales them and applies transient colors. Per-species original credit histories and original AnimData.xml files are retained in this folder. The table credits every contributor listed in those histories; detailed animation assignments remain in each credits.txt.
